# Art Source

Эта папка — **склад сырых ассетов** от автора проекта: текстур, моделей, звуков, SFX, готовых партикл-спрайтов, ресурсов с других модов для референса и т.д.

## Что тут лежит

- `rezero-fx-textures.zip` — большой архив (52 MB) с FX и текстурами ReZero-тематики: партиклы огня/душ/плазмы, модели Mjolnir и щитов, broneya-оверлеи для скина, spray-sheet-ы, glow-маски. Использовать как источник при создании новых способностей/предметов — распаковать локально, найти подходящее, перекинуть уже в `src/main/resources/assets/superheroes/textures/...` под нужным namespace.

## Правила

1. **Сюда кидаем всё сырое** — текстурки, которые пользователь прислал, звуки до обработки, исходные blockbench-проекты, референсы. Это не runtime — это материал.
2. **В `src/main/resources/assets/` копируем только то, что реально используется** и уже с правильными именами / путями.
3. **Формат звуков: OGG Vorbis.** Minecraft не умеет MP3. Если пришёл MP3 — конвертировать через `ffmpeg -i in.mp3 -c:a libvorbis -qscale:a 5 out.ogg`.
4. **Формат текстур: PNG**, power-of-two размеры (16×16, 32×32, 64×64 и т.д.). Прозрачность — альфа-канал.
5. **Крупные файлы ок** (до 100 МБ — лимит GitHub), но если скопится больше 500 МБ суммарно — подумать о git-lfs или внешнем хостинге.
6. **Лицензии**: если ассет откуда-то скачан, положить рядом `LICENSE.md` или `source.txt` с ссылкой.

## Как пользоваться архивом из Devin

Когда Devin делает новую способность/эффект и нужна текстура:

```bash
unzip -l art-source/rezero-fx-textures.zip | grep -i <what-you-need>
unzip -p art-source/rezero-fx-textures.zip "FX + TEXTURES REZERO/.../some.png" > /tmp/some.png
# дальше — обработать и положить в src/main/resources/assets/superheroes/textures/...
```
